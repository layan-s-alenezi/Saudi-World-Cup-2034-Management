# Saudi FIFA World Cup 2034 Management System

A C++ academic project developed to manage football tournament information for the Saudi FIFA World Cup 2034.

## Project Overview

This console-based application manages information about football matches, teams, football fields, and cities. It demonstrates object-oriented programming concepts and the implementation of fundamental data structures.

## Features

- Display, insert, delete, modify, and search tournament records.
- Manage matches, teams, football fields, and cities.
- Store records using linked lists.
- Convert linked-list records into stacks and queues.
- Navigate through an interactive console menu.

## Technologies Used

- **Language:** C++
- **Programming Concepts:** Object-Oriented Programming (OOP), Classes, Templates, Pointers
- **Data Structures:** Linked Lists, Stacks, Queues

## How to Run

1. Download the C++ source code.
2. Compile the code using a C++ compiler.
3. Run the compiled program.
4. Use the console menu to manage tournament information.
